Built for board games, tabletop sessions, raffles and picking turn order. Set up how numbers are generated, then tap one big button as often as you like.

- Min/max ranges, 1–100 numbers per draw, optional unique values
- Output as tiles, a summed total, or digits joined into one code
- One-tap presets plus your own, a 50-draw history, and haptics
- Settings persist locally; no analytics, no server
